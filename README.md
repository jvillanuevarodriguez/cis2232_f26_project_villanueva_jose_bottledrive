# Bottle Drive Log

## Project Group

BA / Business Client: Kay Pitre  
Developer: Jose Villanueva  
Project Manager / QA: Steven Nguyen

## Description

This web application will allow a volunteer running a fundraising bottle drive to record each donation as it is taken in, and to keep a history of all donations for the drive.

For each donation, the user enters the depositor's name, the date, and the number of small and large containers received, along with the deposit rate paid for each container type. The application calculates the refund owed for each container type and the total refund for that donation, and stores those amounts with the record.
